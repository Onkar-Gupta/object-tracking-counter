track-counter

Count people crossing a line in a video, and see how accurate the count really is. Every accuracy number comes from MOT17 ground truth, with the pass marks written down before each run.

Code and README Release v1.1.0

What it does

Clean scene

Two students who never overlap: counted in 2, out 0. You click two points to draw the line, and the tool gives the annotated video, the counts and an events file.

Crowded scene

The hard case. Boxes overlap in about 64% of the frames and many people in the crowd get no box. This count is not checked against ground truth.

How well does it count?

Measured on MOT17 sequences 02, 04 and 09 (static cameras), 146 true crossings, feet anchor, with settings tuned on 02 and 04 only.

DetectorPrecisionRecallF1
Public FRCNN detections (baseline)0.9070.4660.615
YOLOX-s single pass (the default, 19 fps on CPU)0.6550.4930.562
YOLOX-s fine-tuned on other MOT17 scenes (weights not published)0.7520.5820.656

The pass mark, fixed in advance: a clear recall gain over the baseline and precision of at least 0.80. No detector passes at either anchor, and the README says so.

Who gets missed

82%of crossings by clearly visible people (70% or more) are counted: 58 of 71
9%of crossings by people under half visible are counted: 6 of 67
19 fpson a laptop CPU at 1080p (2.1 fps with the slower tiled mode)

The counter works when people are visible and separate. Counting is mostly a detection problem, and part of the gap is that MOT17 labels whole bodies even when most of a person is hidden.

Small check on unseen scenes

On four stock clips with the shipped defaults: on the crowded crosswalk, 33 of 41 predicted crossings looked correct and 8 were doubtful; on the clean scene, both students were counted and nothing else. The reviewer is the author, the samples are tiny, and this is a sanity check, not a benchmark.

Try it yourself

git clone https://github.com/Onkar-Gupta/object-tracking-counter && cd object-tracking-counter
pip install -e ".[onnx]"
curl -L --create-dirs -o models/yolox_s.onnx https://github.com/Megvii-BaseDetection/YOLOX/releases/download/0.1.1rc0/yolox_s.onnx
track-counter draw-line --video my_video.mp4
track-counter run --video my_video.mp4 --line X1,Y1,X2,Y2 --save-video counted.mp4

For the browser demo shown above: pip install gradio==6.31.0 then python demo/app.py. A Docker image is in the repository too.
